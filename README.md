# FabScreen Website Redesign

An independent student website redesign project for the IIM Bangalore BBA DBE Web Development final project.

## Current status
- Homepage prototype
- Responsive navigation
- Separate HTML, CSS and JavaScript files

## Run locally
Open `index.html` in a browser.

## Project structure
- `index.html` — homepage
- `css/style.css` — site styling
- `js/script.js` — mobile navigation interaction
- `assets/` — images and other media (to be added)
- `products/` — product pages (to be developed)

## Note
This is an independent redesign prototype, not the official FabScreen website. Business claims and product descriptions should be verified with the business before publication.
